# Huawei E173 Multi-Modem Control Suite

Высокоскоростное приложение на **Go** с нативным графическим интерфейсом (**Fyne**) для одновременного параллельного управления пулом 3G-модемов **Huawei E173** (SMS-фермы, USSD-серверы, мониторинг симок).

## Основные возможности

1. **Главная (Dashboard):**
   * Сводные карточки в реальном времени: Всего модемов, Готовы к работе, Требуют внимания (без SIM).
   * Блок быстрых групповых действий (Массовый USSD, немедленное пересканирование).
   * Краткая справка по работе с пулом.

2. **Модемы (Два режима отображения):**
   * **Табличный вид:** подробная информация по колонкам (`#`, `Порт`, `IMEI`, `Модель`, `SIM`, `Оператор`, `Сигнал % и dBm`, `Баланс / USSD`, `Статус`).
   * **Матричный вид (Плитка 7х7 / 49 слотов):** идеален для фермы большого количества модемов на одном экране.
     * Цветной индикатор статуса: 🟢 Зеленый (В сети), 🟠 Оранжевый (Онлайн, но нет SIM), 🔴 Красный (Ошибка).
     * Отображение номера слота, порта, оператора и последних цифр IMEI.
     * Быстрый выбор любого модема в один клик.

3. **Управление:**
   * **USSD / Баланс:** отправка запросов и декодирование кириллических UCS-2 Hex ответов.
   * **SMS Сообщения:** отправка текстовых SMS с выбранного модема.
   * **AT-Терминал:** интерактивная консоль ввода любых AT-команд в реальном времени.

4. **Лог событий (Отдельная вкладка):**
   * Чёткий, контрастный читаемый журнал всех системных действий.
   * Кнопка «Очистить лог».
   * Кнопка «Сохранить в файл» (экспорт лога в текстовый файл с таймстемпом).

5. **Настройки:**
   * Скорость COM-порта (Baudrate: 9600 - 230400).
   * Интервал мониторинга сети (3с, 5с, 10с, 30с).
   * Переключение темы оформления (**Тёмная / Светлая**).

---

## Запуск

```bash
./e173-control
```
